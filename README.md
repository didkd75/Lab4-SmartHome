# SmartHomeApp — Laboratory Work #4

Консольний додаток на C# (.NET 10), що моделює систему **«Інтелектуальний розумний дім»**.  
Проєкт виконано в рамках лабораторної роботи №4 з дисципліни **«Об'єктно-орієнтоване програмування»** на тему **«Статичні поля, властивості, методи»**.

## 📌 Що реалізовано в Lab-4
- **Статичні поля, властивості та статичний конструктор:**
  - `DeviceCounter` (`public static int`) — лічильник створених екземплярів класу `SmartDevice`, що автоматично змінюється при створенні та видаленні об'єктів.
  - `ElectricityTariff` (`public static double`) — спільний для всієї системи тариф на електроенергію (грн/кВт·год), який ініціалізується у статичному конструкторі (`static SmartDevice()`).
- **Статичні методи (`Static Methods`):**
  - `CalculateTotalPowerAndCost(List<SmartDevice>)` — підраховує сумарну активну потужність пристроїв та добові витрати електроенергії за поточним тарифом.
  - `Parse(string s)` — перетворює рядок формату `SerialNumber,DeviceName,Type,PowerUsage,IsActive` в об'єкт `SmartDevice` із генерацією інформативних виключень у разі помилок.
  - `TryParse(string s, out SmartDevice device)` — безпечно парсить рядок через `Parse` без аварійного завершення програми.
- **Перевизначення `ToString()`:** Повертає рядкове представлення об'єкта, сумісне з методами `Parse` / `TryParse`.
- **Оновлене консольне меню:** Додано створення об'єкта через рядок (пункт `1.6`), відображення лічильника екземплярів у таблиці перегляду (пункт `2`) та окремий пункт меню `6 – Продемонструвати static-методи`.

## 🛠️ Структура проєкту
* `DeviceType.cs` — перелік (`enum`) типів пристроїв розумного дому.
* `SmartDevice.cs` — основний клас моделі пристрою зі статичними членами, властивостями, конструкторами та методами.
* `Program.cs` — консольний інтерфейс користувача та тестування функціоналу.
